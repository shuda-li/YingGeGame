# 《踏鼓》豆包像素素材提示词套件

> 用途：用豆包（Seedream 4.0 / 5.0）「上传参考图 + 提示词」生成英歌舞主题的像素风游戏素材。
> 适用素材：主角·英歌槌手、巡逻兵、场景与道具、UI 图标。
> 配套规格：见 `project-drumbeat-art-asset-manifest.json`；帧数约束见 `drumbeat-m0/drumbeat/data/frame_data.json`。

---

## 0. 三条铁律（先看这里，否则素材一定不好用）

1. **分两步走，不要一次要全套。**
   先只生成一张「角色定妆参考图」把长相定死；之后每个动作状态都上传这张定妆图当参考图（可同时传真实妆造照片 + 定妆图，共两张参考图），否则同一个角色每张脸都不一样。

2. **豆包出的是 1K/2K 的「像素风格画」，不是真 36×72 像素画。**
   所以提示词必须强调「大颗粒、像素块清晰可见、无抗锯齿」；拿到图后必须用**最近邻降采样**缩到目标网格，不能直接用。

3. **别指望 AI 出精确帧数、透明底、网格对齐。**
   用纯色底出图后自己抠；动作帧数靠 Aseprite 补到 `frame_data.json` 的数量；挥槌的 active 帧必须手工对齐到视觉最亮那一帧。

## 1. 通用提示词公式

```
[风格锚定] + [主体：从参考图继承的特征] + [动作/姿态] + [构图与画布] + [像素规格] + [背景] + [禁止项]
```

- **风格锚定**：锁定「16 位复古游戏像素画 / 真像素画 / 非马赛克滤镜」
- **主体**：英歌舞槌手，并强制继承参考图的妆造特征
- **动作**：每次只改这一段，其余全部保持不动
- **构图**：全身、脚底贴底、居中、占比固定
- **像素规格**：无限色、硬边、无抗锯齿、单像素块清晰
- **背景**：纯品红 `#FF00FF`，便于后期抠图
- **禁止项**：负面词（豆包无独立输入框就并到结尾）

## 6.5 提示词 E — 跑步循环「换手」补帧（左右臂前后交替）

> 背景：现有「跑动四帧」全部为右手（持槌）在前、手臂姿态几乎不变，导致跑步循环里手臂僵硬。
> 已通过腿部镜像补出左脚在前帧（`run_4/run_5`），但手臂仍未交换。
> 本提示词用于生成「左手在前、右手在后」的对侧臂帧，与原图帧配对成完整循环。
> 使用方式：**上传 `art-source/picture/跑动四帧.png` 作为唯一参考图**，配合下述提示词。

### E-1 单帧版（推荐，逐帧生成，一致性最好）

```
16位复古游戏像素画风格，真像素画（true pixel art），不是马赛克滤镜、不是模糊降采样。
严格沿用参考图中角色的全部特征：脸谱纹样、头饰羽球、白色披巾、红色戏服结构与纹样、绿色腰封、双英歌木槌、黑白金配色，人物长相、身形、服饰与参考图完全一致，不要做任何改动或简化。

构图：全身完整入画，人物高度与参考图中的角色一致，脚底对齐画面底部，水平居中。
```

### E-4 真实动作基准版（以妆造照片的行进姿为准）

> 用途：原图四帧持槌手始终同侧后摆，不符合「异侧交替」的衔接规范。
> 本提示词以**真实英歌槌手行进照**（前手举槌过肩、后手垂槌于身后）为动作唯一标准。
> 使用方式：**同时上传两张参考图**——①真实动作照片（动作基准）②像素定妆图（长相服饰基准），配合下述提示词。

```
16位复古游戏像素画风格，真像素画（true pixel art），不是马赛克滤镜、不是模糊降采样。

像素规格：每个像素方块大小完全一致、边缘锐利，无抗锯齿、无模糊、无渐变；限色 24–32 色的固定调色板，与第二张参考图同一套颜色，明暗分层用硬边色块。

写实照片、3D渲染、厚涂油画、水彩、模糊、抗锯齿、平滑渐变、马赛克滤镜、伪像素、多个人物、被裁切掉的手或脚、背景建筑、地面阴影、文字、水印、logo、签名
```

> 生成后将该帧与原图四帧按「持槌手前置帧 / 持槌手后置帧」交替排列接入 `RUN_CYCLE`，实现左右手交替挥槌的完整跑动循环。



| 步骤 | 要求 |
|---|---|
| 抠图 | 品红底 `#FF00FF` 一键去背 → 透明 PNG-32 |
| 降采样 | **最近邻**缩到目标网格；主角 36×72，建议保留 @2x 72×144 |
| 对齐 | 脚底中心对齐画布底部，左右居中，不留多余透明边距 |
| 朝向 | 只做「朝右」，朝左由程序水平翻转，无需另出 |
| 补帧 | 用 Aseprite 把 AI 出的关键姿势补到上表的目标帧数 |
| 关键帧对齐 | 挥槌的 **active 帧必须落在视觉最亮那一帧**，否则判定提示与画面错位 |
| 调色板 | 同一批素材统一锁到 24–32 色，避免风格漂移 |
| 命名 | `player_<状态>_<两位序号>.png` / `enemy_patrol_<状态>_<序号>.png` / `<分类>_<名称>.png` |

## 8. 避坑清单

- ❌ 一次让豆包出全套 17 个状态 → 角色长相会漂移，必须用定妆图逐状态生成
- ❌ 直接拿 1024×1024 的图进游戏 → 必须最近邻降采样，否则进游戏一缩放就糊
- ❌ 相信 AI 会自动给透明底 → 一律用纯品红底 + 自己抠
- ❌ 照搬 AI 给的帧数与节奏 → 帧数必须以 `frame_data.json` 为准，手工补帧
- ❌ 不同批次的素材混色调色板 → 会明显看出「不是一个游戏」，需统一限色
- ❌ 巡逻兵前摇画得太含蓄 → 玩家读不出对击时机，节奏玩法直接失效
