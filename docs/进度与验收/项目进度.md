## 三、已知技术限制（不阻塞，但影响观感 / 质量）

1. **背景镜像拼接带来对称重复感**：接缝已用「相邻瓦片左右翻转」消除，代价是同一段建筑会镜像出现。彻底解决需要真正无缝的素材或更宽的横版背景。
2. **`远景层` 四张素材未启用**：`远景层_1~4` 已处理入库，但当前视差配置里没有它们——它们与中景层 `level_map` 空间重叠、层次冗余。留待 M2 做真正的分层远景。
3. **中景层天空区残留贴片**：`level_map` 原画天空区域里有非天空色的装饰图案，无法通过颜色泛洪清除，表现为「浮在天空的图案」。根治需要重新生成一张干净的分层背景。
4. **角色贴图尺寸不统一**：`charge` 高 131px、`run` 高 149px，出招时角色视觉大小会略变。需要在 M2-1 统一到同一基准高度。
5. **缺 `idle` 素材**：站立静止时复用跑动首帧（`run_0`），观感偏「僵直」。
6. **敌人 `idle` 素材未被使用**：巡逻一律用 `walk`，`idle` 目前闲置。
7. **前景灯笼重复感**：前景区每 760px 一盏，间距固定，长距离行进能看出规律。
8. **深坑与关卡范围外是纯黑兜底色**：观感粗糙，后续应替换为暗色砖纹或渐变。
9. **UI 结算素材未接入**：`ui/win.png`、`win_alt.png`、`lose.png` 已入库，但结算界面目前是纯文字。
10. **判定与手感依赖手动调参**：自动延迟校准（T-B04）与配置存档（T-B03）未实现，试玩前需手动设偏移。

## 四、环境与工具链问题

1. **本机 `python` 命令解析不稳定**：有的 shell 会解析到未安装 pygame 的解释器。当前可用的解释器是
   `C:\Pychram\Python云烟\python.exe`（3.12.6，含 pygame 2.6.1）。
   ⚠️ 注意：M0 打包 exe 用的是 **Python 3.10 环境**，与本机日常运行环境不同。
2. **git 访问 GitHub 必须走本地代理**：系统代理在 `127.0.0.1:12450`，但 git 默认不走它。
   已在仓库本地配置里固化：
   ```
   http.proxy=http://127.0.0.1:12450
   http.version=HTTP/1.1
   ```
   大文件推送若报 `RPC failed; curl 55` / `Connection was reset`，加参数重试：
   `git -c http.postBuffer=524288000 push`。
   代理客户端关闭时 git 会失败，需 `git config --local --unset http.proxy` 取消。
3. **本机无 LibreOffice**：`tools/md2docx.js` 生成的 docx 只能做结构校验（段落数 / 表格数 / 关键词在位），无法渲染出图做视觉校验。
4. **无 gh CLI**：仓库创建、PR、Issue 等操作暂时只能靠网页或 git 命令。
5. **素材处理脚本不在仓库内**：`art-source/picture/` → `assets/` 的处理流程（边界泛洪抠图、分帧、同族整数倍缩放）当时写在临时目录、未入库，**目前只有 `assets/manifest.json` 记录了参数**，无法一条命令复现。建议补一个 `drumbeat-m0/tools/build_assets.py`。
6. **`level_map` 抠图坑（已修复，记录防复发）**：`level_map` 是整幅全景图、没有品红底，若从四边全部泛洪，会把下方广场砖栏的灰蓝色像素一并误删，在游戏里透出天空底色形成粉色空洞。正确做法是**只从上边缘泛洪 + 收紧容差**（详见 README「抠图规则」）。
